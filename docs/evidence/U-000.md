## 4. Lectern design

- [DESIGN] `.gitignore` separates dependency, build, runtime-data, local-secret, generated-native and inspection-target classes, so that generated trees can never be committed and operator-supplied inspection artifacts stay out of the repository except for the two exemptions the contract names — follows F§3.1 (`targets/` is gitignored, never committed) and AGENTS.md §5.
- [DESIGN] `scripts/preflight.mjs` is a single zero-dependency Node script with two modes. `--phase <n>` runs every check of phase `n` and of all lower phases, prints one `OK` / `MISSING` line per check, writes `docs/preflight.json`, and exits non-zero when a required check is missing. `--targets` only reports which `targets/` paths exist and always exits 0, so it is always safe to run — follows F§13.
- [DESIGN] Phase gating is cumulative: phase 1 needs Node, pnpm, git and one system font; phase 3 adds `xvfb-run` on Linux; phase 4 adds JDK ≥ 17, `adb` and `ANDROID_HOME`; phase 5 adds `docker compose`. Phases 2 uses the phase-1 set — follows F§13.
- [DESIGN] The missing-check exit status is a hard failure rather than a warning, so a unit that needs a tool cannot silently pass without it — follows AGENTS.md §2 Step 1 and §7 ("Run long-lived processes … report missing system tools").
- [DESIGN] `docs/status.md` is append-only: one row per unit, and a row is never rewritten — follows AGENTS.md §5 ("Append-only" class) and §8.
- [DESIGN] The probe text is original prose written for this project. It carries the six golden sentences of F§5.3 verbatim inside running prose so that the reader's own splitting can be compared with the tokenizer's, plus a decimal, a three-item list, one over-long sentence and one quoted sentence — follows AGENTS.md §3.1 and §4.6 (fixtures are text you write yourself) and the contract's probe requirements.
- [DESIGN] `targets/probe/article.html` carries the same passage as a standards-shaped article so that furniture handling (`header`, `nav`, `aside`, `footer`) can be observed inside a page, which a plain text file cannot show.
- [DESIGN] `targets/probe/serve.mjs` is a zero-dependency static server bound to `127.0.0.1:4173`, the origin the later extension units name, with traversal protection and a single directory root.
